# การนำเข้าชุดข้อมูลสูตรอาหารไทย

แอปใช้ชุดข้อมูล `pythainlp/thai_food_v1.0` จาก Hugging Face จำนวน 159 รายการ ภายใต้สัญญาอนุญาต CC0-1.0

เรียกคำสั่งต่อไปนี้เพื่อดาวน์โหลดข้อมูลต้นฉบับใหม่:

```powershell
npm run import:thai-recipes
```

คำสั่งจะดาวน์โหลดข้อมูลสองหน้า ตรวจสอบว่าครบ 159 รายการ และสร้างไฟล์ `data/thai-food-v1.json` จากนั้น `lib/thai-recipes.ts` จะแยกหัวข้อ `เครื่องปรุง` และ `วิธีทำ` ให้เป็นโครงสร้างของแอป

สร้าง migration สำหรับ Supabase จากไฟล์ข้อมูลปัจจุบันด้วยคำสั่ง:

```powershell
npm run generate:thai-supabase
```

คำสั่งนี้สร้าง `supabase/migrations/004_import_thai_recipes.sql` ซึ่งนำเข้า 159 สูตร วัตถุดิบ และความสัมพันธ์ระหว่างสูตรกับวัตถุดิบ พร้อมลบสูตรตัวอย่างเดิม เมื่อเชื่อมโครงการ Supabase แล้วให้นำ migration ขึ้นฐานข้อมูลด้วย:

```powershell
npm run supabase:link
npm run supabase:push
```

Migration จะเก็บชื่อและรายละเอียดสูตรแบบ snapshot ไว้ในประวัติการทำอาหารก่อนลบสูตรตัวอย่างเดิม จากนั้นตั้งค่าความสัมพันธ์กับสูตรที่ถูกลบเป็น null ทำให้ประวัติของผู้ใช้ไม่สูญหาย

สูตรที่นำเข้าทุกสูตรมีสถานะ `unreviewed` และหมวดอาหาร `Other` โดยตั้งใจ จึงไม่แสดงแก่ผู้ใช้ที่เลือก Vegetarian, Vegan, Halal หรือรูปแบบอาหารแบบจำกัด จนกว่าจะมีผู้ตรวจสอบส่วนผสม อาการแพ้ และความเหมาะสมทางศาสนาแล้ว ห้ามอนุมานสถานะฮาลาลจากชื่อสูตรหรือชนิดเนื้อสัตว์โดยอัตโนมัติ
